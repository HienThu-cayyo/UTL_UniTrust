### 🎓 About the Project

**UniTrust Ledger** is an experimental decentralized application (dApp) exploring how blockchain technology could support academic record management and verification.

The concept focuses on GPA, training points, and the possibility of making academic achievements easier for authorized institutions to issue and third parties to verify.

### 💡 The Idea

The proposed workflow is simple:

**University → Smart Contract → Academic Record → Verification**

- **Universities:** Issue or update academic records.
- **Students:** Have a verifiable digital record of achievements.
- **Verifiers:** Check information through the Stellar network.

### 🛠️ Tech Stack

- **Stellar** — Blockchain network
- **Soroban** — Smart contract platform
- **Rust** — Smart contract development
- **TypeScript** — Client development

### 📁 Project Structure

```text
client/      Frontend application
contract/    Soroban smart contract
```

### 🚧 Project Status

**Experimental prototype**

This repository explores the core concept of blockchain-based academic verification.

The implementation is still experimental and should not be considered a production-ready academic credential system.

### 🌱 Future Possibilities

- Digital skill credentials
- Multi-institution verification
- Non-transferable academic credentials
- AI-assisted career recommendations

These are future concepts, not completed features.
